# AI vs ML vs Deep Learning

**AI** — any system that mimics intelligent behavior.
**ML** — subset: systems that learn patterns from data, no explicit rules.
**Deep Learning** — subset of ML: multi-layer neural networks.
**LLMs** — subset of deep learning: transformers trained on massive text corpora.

```
AI
 └─ ML
     └─ Deep Learning
         └─ LLMs (transformers)
```

**Key distinctions:**
- Traditional ML: hand-crafted features + algorithm (e.g., decision trees, SVMs)
- Deep Learning: learns features automatically from raw data
- LLMs: predict next token; emergent reasoning from scale

**Interview answer:** "LLMs are a type of deep learning model — specifically transformers — which are themselves a type of ML model, which falls under the broader umbrella of AI."
